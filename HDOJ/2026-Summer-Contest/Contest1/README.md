# 2026 “钉耙编程” 中国大学生算法设计暑期联赛（1）

## 1001 小丑牌

1. 由于序列 $a$ 和 $b$ 的顺序对答案没有影响，因此我们可以将两个序列看成是有序序列。
2. 不选技能卡的操作可以看作两个序列中都存在数值为 $0$ 的元素。

由于最后答案是要输出 $(x + a) \times (y + b)$ 的最大值，我们不妨直接考虑 $x + a$ 和 $y + b$ 的情况。

1. 当 $x + a$ 和 $y + b$ 两个序列的最大值都为正数或者最小值都为负数的时候，最后答案一定是一个正数，而且这个正数一定是 $\max(x + a) \times \max(y + b)$ 和 $\min(x + a) \times \min(y + b)$ 中的较大者。
2. 另外一种情况下答案只能是负数，我们要想让答案尽量大，那么就只能选择最大的负数和最小的负数相乘。答案是 $\max(x + a) \times \min(y + b)$ 和 $\min(x + a) \times \max(y + b)$ 中的较大者。

时间复杂度： $O(n)$。
