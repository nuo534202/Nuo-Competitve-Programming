## 1007 G. Perfect Palindrome

令 $g=\gcd(n,2d)$，答案只与每个位置所属的等价类有关。

原因：

1. 对于任意 $k\ge 0$，循环左移 $kd$ 位后的字符串是回文串，因此有 $A_i=A_{n-1-i+2kd}$
2. 不断增加 $2d$，在模 $n$ 意义下能够到达的位置恰好是所有模 $g$ 同余的位置，所以位置 $i$ 与所有满足 $j\equiv i\pmod g$ 的位置字符必须相同。
3. 当 $k=0$ 时，原字符串本身也必须是回文串，所以余数为 $r$ 的位置还要与余数为 $g-1-r$ 的位置相同。

因此位置 $i$ 所属的等价类可以表示为 $\min(i\ \%\ g,\ g-1-i\ \%\ g)$。

对于每个等价类，统计其中每个字符的出现次数。最终该等价类中的字符必须全部相同，所以保留出现次数最多的字符，其余字符全部修改即可。最后将所有等价类中的修改次数相加。

时间复杂度： $O(26n)$。


## 1011 K. Union MEX

答案与树的形状无关，只与节点的点权有关。如果被查询节点的点权为 $1$，那么 MEX 的值为 $0$，否则 MEX 的值为 $\sum\limits_{i=1}^n a_i + 1$。

原因：

1. 如果当前节点点权为 $1$，所有满足条件的点集 $S$ 都包含该节点，所以 $V_r \ge 1$，因此 MEX 为 0。
2. 如果当前节点点权为 $0$，那么 $\min V_r = 0$，并且当 $S = \{r\}$ 的时候 $V_r$ 最小。除了这个 $S$ 点集以外的所有 $V_r$ 值不同的点集 $S'$ 都可以视作根据点集 $S$ 的基础上加上若干条总共包含 $k$ 个点权为 $1$ 的节点的简单路径构成，其中 $1 \le k \le \sum\limits_{i=1}^n a_i$。所以 $V_r = \{1, 2, \ldots, \sum\limits_{i=1}^na_i\}$，因此 MEX 为 $\sum\limits_{i=1}^n a_i + 1$。
   
时间复杂度： $O(n + q)$。
