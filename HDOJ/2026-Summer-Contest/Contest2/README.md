## 1004 坪厕鸡

由于每个队伍只能有一个评测的题目，所以为了方便处理，现将所有提交按照提交队伍分类。

如何处理只有每个队伍只能有一个评测的题目：维护两个优先队列。

- 第一个优先队列存储等待评测的题目，按照题目提交时间从小到大排序
- 第二个优先队列存储正在评测的题目，按照评测结束时间从小到大排序
- 我们只需要保证两个优先队列中每个队伍最多只有一个题目即可。具体做法：
  - 初始往第一个优先队列中放入每一个队伍第一次提交的队伍。
  - 将第一个优先队列中最早提交的题目取出，放入第二个优先队列中，并记录该题目的评测开始时间。
  - 在第二个优先队列达到 $k$ 的大小时，弹出最早结束的题目，并将该题目对应队伍的下一个提交放入到第一个优先队列。

时间复杂度： $O(m (\log k + \log n))$。

## 1008 最遥远的距离

如果给出的条件能够构成一棵树，那么根据给出的 $d$ 值可以发现以下规律：

1. 最大的 $d$ 值是这棵树的直径
2. 最小的 $d$ 值是这棵树直径上最接近中心的节点

对于合法的树，构造方案如下：

1. 先将树的直径构造出来：取每一种 $d$ 值对应节点 2 个（最下 $d$ 值对应的节点可以只有一个）依次连接起来
2. 将剩余节点依次连接到直径对应的节点上：所有剩余的 $d_i = x$ 的节点应该连接到直径上 $d_j = x - 1$ 的节点上面

不合法的情况：

1. 最小的 $d$ 数量超过两个（一棵树的一条直径最多只能由两个最接近中心的节点）
2. $d$ 值不连续
3. 除了最小的 $d$ 值之外，其他的 $d$ 值数量不超过两个
4. 当最小的 $d$ 值只有一个时，不满足 $\max (d) = 2 \min (d) - 1$
5. 当最小的 $d$ 值有两个时，不满足 $\max (d) = 2 \min (d) - 2$

时间复杂度： $O(n)$。

## 1011 键盘杀手

题目等价于要找出最优的消除顺序使得消除的总代价最小。我们不需要一次性找出全局的最优消除顺序，我们只需要考虑相邻两个元素之间的消除顺序即可。

考虑相邻元素 $a_i$ 和 $a_{i+1}$ 两个相邻元素的消除顺序，定义

1. 顺序 0：先消除 $a_i$ 再消除 $a_{i+1}$
2. 顺序 1：先消除 $a_{i+1}$ 再消除 $a_i$

以上两种消除顺序的代价可以利用 dp 处理，假设

1. `cur0`：表示考虑到当前元素采取顺序 0 的代价
2. `cur1`：表示考虑到当前元素采取顺序 1 的代价

状态转移方程为：

- `next0 = min(cur0 + a[i + 1], cur1 + max(a[i - 1], a[i + 1]))`
- `next1 = min(cur0, cur1 + a[i - 1])`
- `cur0 = next0`, `cur1 = next1`

时间复杂度： $O(n)$。
