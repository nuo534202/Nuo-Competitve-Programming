## 1011 奶蛙的奶糖

观察到的性质：

1. 由于 $N$ 的范围是 $1 \le x \le N \le 10^9$，所以可以推断出 $1 \le popcount(N) \le 30$。
2. 由于 $popcount(N)^3 = N >> 1$，所以 $N = 2 \times popcount(N)^3$ 或者 $N = 2 \times popcount(N)^3 + 1$。

整体做法：

1. 在 $[1, 30]$ 的范围内枚举 $popcount(N)$，根据性质 2 计算对应的 $N$ 值。
2. 检验计算出的 $N$ 的值是否符合题目式子的要求。

时间复杂度： $O(30 \times 30 \times q)$。
