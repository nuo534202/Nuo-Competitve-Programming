## 1008 恋恋的排列

1. 先预处理出前缀和，以及不翻转情况下的最大前缀和 $\max s_i$
2. 对于翻转一次的情况，考虑反转区间 $[l, r]$ 存在一个 $l \le i \le r$

- 该区间反转后序列会变成 $a_1$, $a_2$, ..., $a_{l-1}$, $a_r$, $a_{r-1}$, ..., $a_i$, ..., $a_{l+1}$, $a_l$, $a_{r+1}$, ..., $a_n$，位置 $i$ 的前缀和 $s'_i = s_{l - 1} + s_{r} - s_{i - 1}$
- 翻转区间只会改变 $l \le i \le r$ 位置的前缀和，因此我们只需要求 $\max s'_i = \max (s_{l - 1} + s_{r} - s_{i - 1})$。
- 对于每一个固定的 $r$，我们需要求的是 $\max (s_{l - 1} - s_{i - 1})$，也就是要找出满足 $0 \le j \le t < r$ 的两个位置，最大化 $drop = s_j - s_t$
- 我们只需要枚举 $r$，$s_j$ 是 $1 \le j < r$ 中的最大前缀和，并利用线性 dp 维护 drop 和答案的最大值即可。

时间复杂度： $O(n)$。

## 1011 奶蛙的奶糖

观察到的性质：

1. 由于 $N$ 的范围是 $1 \le x \le N \le 10^9$，所以可以推断出 $1 \le popcount(N) \le 30$。
2. 由于 $popcount(N)^3 = N >> 1$，所以 $N = 2 \times popcount(N)^3$ 或者 $N = 2 \times popcount(N)^3 + 1$。

整体做法：

1. 在 $[1, 30]$ 的范围内枚举 $popcount(N)$，根据性质 2 计算对应的 $N$ 值。
2. 检验计算出的 $N$ 的值是否符合题目式子的要求。

时间复杂度： $O(30 \times 30 \times q)$。
